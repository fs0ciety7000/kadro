# Revue de code — tâches 1.1 à 1.3 (11/11/2026, `code-reviewer`)

Tests, clippy, fmt, deny : verts. Codes de sortie conformes à `docs/cli.md` § 3.

## Bloquant
1. **Les erreurs clap réaffichent les valeurs saisies, secrets compris** (`kropa-cli/src/errors.rs:78-123`,
   `lib.rs:156-163`, parseurs de `args.rs`). Ex. `kropa secrets set zipline TOKEN sk-live-ABC123` →
   `unexpected argument 'sk-live-ABC123'` ; idem `--url`, `--var`, `--copy`, et `error.message` en `--json` ; le repli
   `err.print()` aussi. Correction : ne jamais interpoler la valeur (`InvalidValue`, `ValueValidation`, `UnknownArgument`
   positionnel) : nom de l'option ou « argument en trop » seulement, y compris repli et `plain_clap_message`. Fixtures
   trycmd avec une valeur sentinelle absente de tous les flux.

## Important
2. `error.reason` absent du JSON d'erreur (`output.rs:96-105`) ; `cli.md` § 4 impose `{code, reason, message, step}` et
   `secret_in_argument` pour le code 11 (`exec.rs:317`). Ajouter le champ (null par défaut), vérifier dans la fixture.
3. Détection de secret en argument (`exec.rs:243-343`) : faux négatifs (`?key=`, `X-Amz-Signature`, pourcent-encodé,
   fragment `#access_token=`, `;` comme séparateur, mots `key`, `sig`, `auth`, `access_key`, `cookie`, `session` ;
   valeurs `token …`, `ghp_`, `sk-`, `AKIA`, `eyJ`). Faux positif : `--set 'headers.Authorization=Bearer {secret:token}'`
   doit être accepté (valeur faite uniquement de références `{secret:NOM}`). Le refus de `--var` vers un emplacement de
   secret dépend du profil : au lot 1.7.
4. `build.rs` : recompilation à chaque build avec refs packées (`rerun-if-changed` sur un fichier absent) ; `.git`
   fichier (worktree) non géré ; `git` lancé sans vérifier que le dépôt est bien celui du workspace ; pas de `-dirty`.
   Correction : `git rev-parse --git-path HEAD` / `packed-refs` depuis `CARGO_MANIFEST_DIR`, `--show-toplevel` = racine
   du workspace, `rerun-if-changed` sur ces chemins + la ref, suffixe `-dirty`.
5. `template.rs:229` `render_unique` : `try_exists().unwrap_or(true)` transforme EACCES en 100 000 tours ; lien pendant
   jugé libre. Utiliser `symlink_metadata`, propager l'E/S, documenter l'ouverture en `create_new` (même point
   `target.rs:133` avec `--force`).
6. Unicode : rejeter ou remplacer U+200B-200F, U+2028-2029, U+202A-202E, U+2066-2069, U+FEFF dans `validate_file_name`
   et `sanitize`.
7. `Config.language` jamais lu : le brancher avec la précédence `--lang` > config > `LC_*` > `en`
   (`docs/memory/decisions.md`).
